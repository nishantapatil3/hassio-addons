# SearXNG Add-on for Home Assistant

Privacy-respecting metasearch engine, packaged as a Home Assistant add-on.

## Features

- Official SearXNG multi-architecture image
- Persistent configuration and generated secret key
- Persistent favicon and runtime cache
- Configurable public URL and image proxying
- Search engines and advanced settings editable from the add-on config directory

## Installation

Add this repository to Home Assistant and install the SearXNG add-on.
