# Redis Add-on for Home Assistant

Redis in-memory data store, packaged as a Home Assistant add-on.

Useful for caching, session storage, and message passing between add-ons and automations.

## Features

- Redis 7 on Alpine Linux
- Optional password authentication
- Configurable log level
- Optional AOF persistence

## Installation

Add this repository to Home Assistant and install the Redis add-on.
