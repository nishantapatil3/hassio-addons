# Prometheus Add-on for Home Assistant

Prometheus monitoring and time-series database, packaged as a Home Assistant add-on.

## Features

- Prometheus 3 on the official multi-architecture image
- Persistent time-series data stored in the Home Assistant data volume
- Configurable scrape interval, evaluation interval, and retention period
- Optional scraping of Home Assistant's Prometheus integration

## Installation

Add this repository to Home Assistant and install the Prometheus add-on.
