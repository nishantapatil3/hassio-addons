# Nishant's Home Assistant apps

This repository contains Home Assistant apps (formerly called add-ons).

## Installation

Add this repository URL in **Settings > Apps > App store > Repositories**:

```text
https://github.com/nishantapatil3/hassio-addons
```

## Apps

- [LiteLLM](litellm/) — an OpenAI-compatible AI gateway configured for
  OpenRouter, NVIDIA NIM, Claude Code, and Claude Desktop.
