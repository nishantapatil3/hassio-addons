# PostgreSQL 18 Add-on for Home Assistant

PostgreSQL 18 relational database, packaged as a Home Assistant add-on.

## Features

- PostgreSQL 18 on Alpine Linux
- Persistent data stored in HA data volume
- Configurable superuser name, password, and default database

## Installation

Add this repository to Home Assistant and install the PostgreSQL 18 add-on.
